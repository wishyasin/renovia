# Renovia web sitesi

Renovia, kentsel dönüşümde ev sahiplerini ve müteahhitleri buluşturan bir mobil uygulamadır. Bu depo yalnızca uygulamanın herkese açık sayfalarını barındırır ve GitHub Pages ile yayınlanır:

**https://wishyasin.github.io/renovia/**

| Sayfa | İçerik |
|---|---|
| [Gizlilik](https://wishyasin.github.io/renovia/gizlilik.html) | Gizlilik politikası |
| [KVKK](https://wishyasin.github.io/renovia/kvkk.html) | KVKK aydınlatma metni |
| [Kullanım koşulları](https://wishyasin.github.io/renovia/kosullar.html) | Kullanım koşulları |
| [Hesap silme](https://wishyasin.github.io/renovia/hesap-silme.html) | Hesabın ve verilerin nasıl silineceği |
| [Destek](https://wishyasin.github.io/renovia/destek.html) | Yardım ve iletişim |

`davet.html`, `ilan.html` ve `firma.html` uygulamadan paylaşılan bağlantıları açar.

Uygulamanın kaynak kodu ayrı ve gizli bir depoda tutulur.
